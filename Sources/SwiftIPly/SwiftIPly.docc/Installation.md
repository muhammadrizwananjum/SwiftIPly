# Installation

### Swift Package Manager

Add IPly to your project via Xcode:
1. File > Add Packages...
2. Enter package URL: `https://github.com/yourusername/IPly`
3. Select version rules

Or add to your `Package.swift`:
```swift
dependencies: [
    .package(url: "https://github.com/yourusername/IPly.git", from: "1.0.0")
]
